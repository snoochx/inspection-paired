# Парная инспекция кода (Java)

## Описание работы

Данный репозиторий создан для выполнения практической работы по теме **парная инспекция исходного кода**.

Цель работы — провести систематическую проверку программного кода двумя разработчиками для выявления:

- логических ошибок;
- нарушений стандартов оформления;
- проблем читаемости;
- потенциальных уязвимостей;
- ошибок проектирования.

## Участники

Работа выполняется двумя разработчиками в отдельных ветках репозитория.

- Ветка `my-branch` — код первого участника
- Ветка `friend-branch` — код второго участника

## Задание

Каждый участник должен:

1. Написать собственную программу на Java (не менее 50 строк).
2. Разместить код в своей ветке.
3. Передать код партнеру для проверки.
4. Выполнить инспекцию кода второго участника.
5. Подготовить список замечаний и рекомендаций.

## Что проверяется при инспекции

Во время анализа кода оцениваются:

- корректность логики программы;
- структура проекта;
- читаемость и стиль написания;
- именование переменных и методов;
- обработка ошибок;
- повторяющийся код;
- соблюдение принципов ООП;
- наличие потенциальных уязвимостей.

## Используемые технологии

- Java
- Git
- GitHub

## Результат работы

В репозитории размещены:

- два отдельных проекта на Java;
- две рабочие ветки участников;
- результаты инспекции каждого проекта;
- история изменений в Git.

## Вывод

Парная инспекция позволяет повысить качество программного кода, обнаружить ошибки на ранних этапах разработки и улучшить навыки командной работы.
